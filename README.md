# 🌱 Plookphak

บันทึกการยืมเงินระหว่างเพื่อน แทนการจดกระดาษ: คิดดอกเบี้ยรายวัน ค่าปรับรายชั่วโมงเมื่อเลยกำหนด อัปสลิปให้ผู้ดูแลตรวจ และรองรับการจ่ายเงินสด

| ส่วน | ใช้ | ค่าใช้จ่าย |
|---|---|---|
| หน้าเว็บ | React 19 + Vite + Tailwind 4 (PWA ติดตั้งลงมือถือได้) | — |
| ฐานข้อมูล / ล็อกอิน / เก็บสลิป | Supabase (Postgres + Auth + Storage + pg_cron) | ฟรี |
| Hosting | Cloudflare Pages | ฟรี |

| เพิ่มผู้ยืม แก้ไขรายการ ตรวจสลิป รับเงินสด | | ✅ | ✅ |

สิทธิ์บังคับที่ฐานข้อมูล (Row Level Security) ไม่ใช่แค่ซ่อนปุ่ม ผู้ยืมจึงอ่านข้อมูลคนอื่นไม่ได้แม้จะเรียก API ตรง

## สูตรเงิน

```
ยอดที่ต้องจ่าย ณ เวลา t = เงินต้น
  + ดอกต่อวัน × จำนวนวัน        (วันเริ่มคิดดอกนับเป็นวันที่ 1, ตามเวลาไทย, คิดต่อแม้เลยกำหนด)
  + ค่าปรับต่อชม. × ชม.เต็มที่เลยวันครบชำระ  (เลยครบ 1 ชม. จึงเริ่มปรับครั้งแรก)
```

- **นาฬิกาหยุด** ณ เวลาที่ยอดจ่ายสะสม (อนุมัติแล้ว + สลิปรอตรวจ) ครอบคลุมยอดที่ต้องจ่าย ณ เวลานั้น
- ผู้ยืมอัปสลิป → หยุดที่เวลาอัปโหลด (ฐานข้อมูลบังคับเวลาเอง แก้จากหน้าเว็บไม่ได้)
- สลิปถูกปฏิเสธ → ไม่นับ นาฬิกาเดินต่อย้อนหลังเหมือนไม่เคยส่ง
- จ่ายบางส่วนได้ แต่นาฬิกาหยุดเมื่อจ่ายครบเท่านั้น
- เงินสด: admin กด "รับเงินสด" เลือกเวลาที่รับ ถือว่าผ่านทันที

สูตรอยู่ 2 ที่ และต้องตรงกัน: `src/lib/loanMath.ts` (หน้าเว็บ) กับ `public.loan_owed` ใน migration (ใช้กับระบบเตือน)

## แจ้งเตือน

แจ้งเตือนอยู่ในแอป (แท็บ "กิจกรรม" มีจุดชมพูเมื่อมีรายการใหม่):
- ผู้ยืมส่งสลิป → admin ทุกคน
- สลิปผ่าน/ไม่ผ่าน, มีรายการยืมใหม่, รับเงินสด → ผู้ยืม
- ใกล้ครบกำหนด 24 ชม. และเริ่มโดนปรับ → ผู้ยืม (+ admin) ผ่าน pg_cron ทุก 15 นาที

## รันในเครื่อง

ต้องมี Docker

```bash
npm install
npx supabase start -x studio,logflare,vector,imgproxy,edge-runtime,mailpit,postgres-meta,realtime,supavisor
npx supabase db reset
```

คัดลอก `PUBLISHABLE_KEY` ที่ได้ใส่ `.env.local` (ดู `.env.example`) แล้ว `npm run dev`

บัญชีทดสอบอยู่ใน `supabase/seed.sql` (ใช้กับเครื่องตัวเองเท่านั้น)

```bash
npm test            # ทดสอบสูตรเงิน
npm run test:rls    # ทดสอบสิทธิ์ 28 ข้อ กับ Supabase ในเครื่อง (รันหลัง db reset)
```
